## 📌 简介

StarGate 是 TAI Research 为 GTC 系列模型量身打造的**轻量级基准测试**。它不追求大而全的评测覆盖，而是聚焦于解决模型在实际落地中遇到的**核心痛点**：

- **防重复**：模型是否会陷入复读机模式
- **逻辑一致性**：模型是否会自相矛盾
- **身份认知**：模型是否知道「我是谁」
- **指令遵循**：模型是否能准确执行用户指令

---

## 🎯 设计理念

| 原则 | 说明 |
|------|------|
| **轻量** | 50-200 个测试用例，几秒钟跑完 |
| **聚焦** | 只测你最关心的问题，不测无关指标 |
| **可迭代** | 每次 SFT 后跑一遍，立刻知道进步还是退步 |
| **可扩展** | 随时可以添加新的测试用例 |

## 🚀 快速开始

### 1. 运行评测

```bash
cd /data/coding/minimind/benchmark

python stargate.py \
    --model ../out/gtc2.5_400M_sft.pth \
    --cases stargate_cases.jsonl
```

## 📊 测试用例分类

| 类别 | 标识 | 数量 | 说明 |
|------|------|------|------|
| 防重复 | REP | 20+ | 测试模型是否会反复输出相同内容 |

## ➕ 如何添加新用例

在 `stargate_cases.jsonl` 末尾追加一行：

```json
{"id": "REP-011", "category": "防重复", "user": "请列举5个中国的省份", "forbidden_keywords": ["广东"], "max_new_tokens": 128}
```

**字段说明**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | ✅ | 唯一标识符 |
| `category` | string | ✅ | 用例分类 |
| `user` | string | ✅ | 用户提问 |
| `expected_keywords` | list | ❌ | 回答中必须包含的关键词 |
| `forbidden_keywords` | list | ❌ | 回答中不能重复出现的关键词 |
| `expected_answer` | string | ❌ | 回答中必须包含的精确内容 |
| `max_new_tokens` | int | ❌ | 最大生成长度，默认 512 |
